# Guitar and bass sounds

All of these recordings are from [FreePats](https://freepats.zenvoid.org/), released under the
[Creative Commons CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) public domain dedication.

Each file is named by the MIDI note it was recorded at. The app plays the nearest recording for every
other note, a little faster or slower. It trims each recording to 4.5 seconds and evens out the volume.
Only part of each original set is here: one velocity layer, and for some sets a recording every two or
three semitones.
